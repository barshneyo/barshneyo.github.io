# Barshneyo

Blank static website. No build step.

## Deploy

- **GitHub Pages:** push these files to a repo (e.g. `barshneyo.github.io`), then Settings → Pages → deploy from the `main` branch, root folder.
- **Netlify:** drag this folder onto app.netlify.com/drop.
- **Vercel:** `npx vercel` inside this folder.
